# Core Academic Portal

A Java-first student academic management and analytics portfolio. The same Java domain model powers the console application and the deployed browser experience.

## Java features

- Interactive dashboard with class averages, honors, probation, earned credits and improvement indicators
- Student ranking by GPA, name, year or strongest subject
- Free-text student search across ID, name, year and academic standing
- Detailed student reports with credit completion, strongest/weakest subjects and score consistency
- Subject analytics with class average, highs, lows, spread and pass percentage
- Year-level analytics and credit summaries
- Academic risk monitoring for low GPA, failing subjects and low credit completion
- GPA / letter-grade distribution analysis
- Live score entry with validation through the existing `InvalidGradeException`
- Enrollment status toggling
- CSV export of the complete roster and derived analytics
- Roster integrity audit for duplicate IDs, invalid credits, invalid scores and empty subject sets
- Existing weighted-GPA, honor-roll, probation, subject leaderboard and edge-case demonstrations remain available through `Main`

## Browser portfolio

The portfolio version is not a Java server pretending to be a website. `PortfolioApp.java` is compiled from Java to browser JavaScript with TeaVM, so the Java calculations and interaction logic execute client-side on GitHub Pages.

The deployed page includes:

- Java-powered dashboard
- Searchable/sortable student table
- Individual student profiles
- Live score updates with validation
- Enrollment toggling
- Subject analytics
- Academic risk monitor
- CSV export generated by the Java data model

HTML/CSS is intentionally minimal: the application behavior and analytics remain in Java, while the page only provides the shell and presentation layer.

## Run locally

### Console application

```bash
mkdir -p out
javac -d out src/*.java
java -cp out Main
java -cp out AcademicPortal
```

### Browser portfolio

```bash
mvn clean package
python -m http.server 8080 -d site
```

Then open `http://localhost:8080`.

## Build system

The project uses Maven plus TeaVM 0.15.0 for the browser compilation. TeaVM produces the JavaScript bundle under `site/teavm/classes.js`. GitHub Actions builds that bundle and deploys the `site/` directory to GitHub Pages.

## GitHub Pages

The live portfolio is a static GitHub Pages site, but the application logic is still Java: Java is compiled ahead of time to JavaScript for browser execution. No Java server or backend is required at runtime.

## Project structure

- `src/Main.java` — original console demonstration
- `src/Student.java` — core student, subject, GPA and validation model
- `src/AcademicPortal.java` — advanced console management suite
- `src/PortfolioApp.java` — TeaVM browser entry point and portfolio UI logic
- `index.html` — intentionally small static shell
- `pom.xml` — Maven + TeaVM build configuration
- `.github/workflows/java-ci.yml` — Java compile/browser bundle validation
- `.github/workflows/deploy.yml` — GitHub Pages deployment
